# CloudChat – Cloud-Based Chat Application

## Project Overview
CloudChat is a cloud-based chat application designed to support real-time messaging using AWS services.

## Technologies Used
- HTML
- CSS
- JavaScript
- AWS API Gateway WebSocket API
- AWS cloud services

## Features
- Chat user interface
- Real-time communication using WebSocket
- Cloud-based connectivity
- Responsive user interface

## AWS Integration
The application connects to its configured AWS WebSocket endpoint for messaging. Additional AWS services are used as configured in the project.

## How to Run Locally
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run `index.html` using a local development server, if required.
4. Ensure the configured AWS WebSocket endpoint and related backend services are available.

## Security
Do not commit AWS secret access keys, passwords, or private credentials to this repository.
